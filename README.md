# Course Enrollment and Rating Analysis Using Python

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of course metadata and learner rating datasets. The objective is to understand course popularity, explore learner rating behaviour, and identify the most-rated courses.

## Objectives
- Explore course metadata and learner rating datasets.
- Identify the most popular course genres.
- Analyze learner rating patterns.
- Find the top 20 most-rated courses.
- Visualize findings through charts and graphs.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings
- Backend Development was the most common course genre, with 78 courses.
- Machine Learning ranked second, with 69 courses.
- The top 20 most-rated courses accounted for approximately 63.3% of all rating records.
- Users provided an average of approximately 6.88 ratings each.
